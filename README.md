# GeoDoodle

A Turkish-first, bilingual (tr/en) PWA game where players draw country/province/state borders from memory or by tracing, and get scored on accuracy.

## Map data attribution

- Country boundaries © [Natural Earth](https://www.naturalearthdata.com/) (public domain)
- Turkish province boundaries © [geoBoundaries](https://www.geoboundaries.org/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/))
- US state boundaries © Natural Earth (public domain)

See `scripts/generate_geo_data.js` for how region geometry is generated from these sources.
